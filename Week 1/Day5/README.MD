# Task 5 – Weekly Project & Revision

## Sales Analytics Dashboard – Week 1

### Overview

This project is the final practical task of Week 1, combining the Excel skills learned throughout the week into an interactive Sales Analytics Dashboard.

The project focuses on data cleaning, Excel formulas, data analysis, Pivot Tables, Pivot Charts, Slicers, and dashboard development to generate meaningful business insights from sales data.

---

## Objectives

- Review and apply Excel formulas and functions
- Perform data cleaning and validation
- Use sorting and filtering for data analysis
- Work with Excel Tables
- Create and analyze Pivot Tables
- Create Pivot Charts for visualization
- Use Slicers for interactive filtering
- Build a professional Excel dashboard
- Generate business insights from sales data

---

## Dataset

- **Dataset:** Sales Performance Dataset
- **Records:** 103 cleaned records
- **Tool:** Microsoft Excel 2016
- **Currency:** PKR

The dataset contains sales-related information used to analyze orders, quantities, categories, cities, payment methods, customer status, and sales trends.

- Total Orders
- Total Quantity

- Sales by Category
- Sales by City
- Sales by Payment Method
- Monthly Sales Trend
- Category Slicer
- City Slicer

- Customer Status Slicer
- Order Date Filter

The dashboard allows users to interactively filter the sales data using slicers.

---

## Key Analysis

The dashboard was developed to answer important business questions such as:

1. Which category generates the highest sales?
2. Which city has the highest sales performance?
3. Which payment method is most commonly used?
4. How do sales change over time?
5. Which areas or categories may require improvement?

---

## Business Insights

Based on the dashboard analysis:

- Accessories generated the highest sales among the analyzed categories.
- Lahore recorded the highest sales among the cities.
- Credit Card was one of the leading payment methods based on the analyzed sales distribution.
- Monthly sales trends were analyzed to identify changes in performance over time.
- Lower-performing categories can be targeted with promotional strategies to improve overall sales.
