# Day 2 – Excel Functions & Data Analysis

## Overview

For Day 2 of my internship, I worked on Excel functions and formula-based data analysis using the Employee Sales Performance dataset.

The dataset contains 200 employee records. I used different Excel functions to analyze sales, departments, regions, employee performance, and other business information.

## Functions Practiced

- IF
- AND
- OR
- IFERROR
- SUMIF
- SUMIFS
- COUNTIF
- COUNTIFS
- AVERAGEIF
- AVERAGEIFS
- INDEX
- MATCH
- TEXT Functions
- DATE Functions
- Logical Functions
- Formula Auditing

## Analysis Performed

I performed:

- Department-wise total sales analysis
- Department and region-wise sales analysis
- Employee counting using COUNTIF and COUNTIFS
- Average sales analysis using AVERAGEIF and AVERAGEIFS
- Employee information lookup using INDEX and MATCH
- Text formatting and extraction
- Date calculations
- Employee performance classification using logical functions


## Key Learning

This task helped me understand how Excel functions can be combined to analyze data and solve different business-related questions. I also learned how formula auditing can help identify and understand formula errors.
